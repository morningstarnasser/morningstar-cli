# Morningstar CLI — Konzeptauswahl

## A · Prompt Star — gewählt

Ein präziser Morgenstern trägt im Zentrum ein negativ ausgespartes Terminal-
Chevron. Die eine Form liest sich zuerst als Stern und im zweiten Blick als `>`.
Damit verbindet die Marke Orientierung und aktives Ausführen ohne zusätzliche
Dekoration.

Datei: `concepts/01-prompt-star.svg`

## B · Dawn Cursor

Ein vierstrahliger Stern steigt über einer Cursorlinie auf. Die Idee erzählt den
Tagesanfang im Terminal direkt, ist aber als Signet weniger eigenständig und
benötigt zwei getrennte Elemente.

Datei: `concepts/02-dawn-cursor.svg`

## C · North M

Zwei Terminal-Chevrons formen ein kantiges `M`; ein kleiner Nordstern markiert
die Mitte. Das Monogramm ist kompakt, wirkt jedoch stärker wie ein
Software-Initial als wie ein souveräner Orientierungspunkt.

Datei: `concepts/03-north-m.svg`

## Entscheidung

`Prompt Star` gewinnt: eine Idee, eine Silhouette, eine echte Doppellesbarkeit
und die stabilste Erkennung bei 16 px. Das Chevron ist kein aufgesetztes Detail,
sondern wird aus dem Stern herausgeschnitten.
