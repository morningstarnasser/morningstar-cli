# Morningstar CLI 1.1.0 — 2026-11-24

The release combines the completed session, image, work-log, autonomous-swarm,
private Remote Control and shared-knowledge changes with Windows installation fixes.

## Interaction changes

- Tab cycles Normal → Plan → YOLO; Shift+Tab reverses. Plain Tab still accepts an open completion.
- The mode remains visible beneath the composer, and leaving YOLO clears its startup bypass flags.
- Code and tool rows have clickable Details markers, including completed Ink Static rows.
- The detail reader retains captured code, tool output and diffs, supports selection/copy, and leaves execution running.
- Tool previews use four bounded lines with neutral text, green success headings, blue commands and red errors.
- Added/deleted diff lines have green/red backgrounds and colored counts; full code details retain syntax colors.
- Scrollback shows new-update notifications; wheel-to-bottom, the Live footer and End/Esc return to the latest output without typing.

## Windows changes

Known vendor npm entry points run through Node directly, with literal arguments.
Git Bash and grep are resolved explicitly. Command hooks use Git Bash. Foreground
cancellation terminates the owned Windows process tree. Claude print mode uses the vendor-supported `--tools ""` and denies MCP tools;
this avoids the Windows Bash/PowerShell deny-list startup error. See the
[official CLI reference](https://code.claude.com/docs/en/cli-reference#cli-flags).
Fatal unhandled CLI rejections now return a nonzero exit code. Closed MCP stdin pipes no
longer cause uncaught EPIPE crashes. Image drops accept Windows quoting and paths;
image reads check symlink/file identity where O_NOFOLLOW is unavailable.

Tests isolate USERPROFILE as well as HOME. POSIX permission-bit assertions are
conditional; they do not substitute for Windows ACLs. Generated files use LF on
both platforms. The previous dirty Windows checkout is preserved; the release is
installed beside it and the global npm command is linked to the new checkout.

## Verification

- macOS: typecheck/build and 592 passing tests, zero failures.
- Windows: typecheck/build and 589 passing tests, zero failures, three explicit skips
  (two existing POSIX settings/symlink cases and unavailable OS sandbox support).
- OSV: zero findings for root and website lockfiles on both machines; the private
  Windows QMD runtime also passed with zero findings.
- Actual PTY keyboard/mouse read-back: forward/reverse mode cycling, leaving startup
  YOLO, unchanged draft, command completion, opening static tool details and code,
  scrolling to the final retained line, live updates during inspection and return
  to live without typing. Screens checked at 120 and 60 columns for mode controls.
- UI workload is synthetic; the terminal, input handlers, scrollback mirror,
  registry, copy controls and rendering are real. Model authorization is verified
  separately per provider; an installed binary or cached model is not proof of access.

No new public endpoint or external deployment is enabled by this release. The
existing private Remote Control authentication/origin/CSRF tests remain in the suite.
The historical README is archived instead of deleted. Local operational evidence
and provider/login status are recorded in the Obsidian release note, not committed
credentials or account-specific state.
